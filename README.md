`mocap4r2_qualisys_driver` streams Qualisys Track Manager (QTM) into
[MOCAP4ROS2](https://mocap4ros2-project.github.io), with the Qualisys C++ SDK (RT
protocol 1.28, MIT license) included in `ThirdParty/`.

Documentation: https://mocap4ros2-project.github.io/latest/systems/qualisys.html
